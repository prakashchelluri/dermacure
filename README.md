# Dr. Sahitya's Dermacure — website

Static site, served with GitHub Pages from the root of `main`.

The pages are generated by `build.mjs` in the project folder (not in this repo). To update the site, run `node build.mjs` there and copy the contents of the `dermacure/` folder here.

## Edited directly in this repo (17 Nov 2026)

These changes were made to the built files here and are **not yet in `build.mjs`**. Re-running the build and copying its output over this repo will undo them until `build.mjs` is updated to match:
